# 支出统计更新

本次需同时部署 `index.html` 与 `deploy/gem-api/server.py`，并重启 gem-api。
已有 Docker 部署请使用 `deploy/docker-deploy.sh` 全量更新；仅运行 `update.sh` 不会更新数据接口。

所有用户可查看支出。管理员输入原管理口令后，服务器签发有效期为 12 小时的支出操作凭证。凭证只保存在当前浏览器会话中，数据服务重启后需重新授权。
服务端使用现有口令摘要验证，也可通过 `GEM_ADMIN_HASH` 环境变量配置摘要（页面口令摘要需同步更新）。

首次加载内置附件记录共 53 笔，总金额 14,883 元：硬件 3 笔 / 2,504 元，账号 5 笔 / 2,158 元，购菜 33 笔 / 7,871 元，点卡 12 笔 / 2,350 元。
管理员首次成功授权后同步至现有数据行。云端已有支出时以云端为准，空列表也不会重新导入；旧版页面不包含支出字段的写入会保留服务器支出。
附件中重复日期及金额的独立记录均保留，多区服点卡记录的价格为该笔总金额，不按区服重复累加。

回归验证：在项目根目录运行 `python test_expenses_api.py`，覆盖授权、非法价格拒绝及旧客户端保留支出。
